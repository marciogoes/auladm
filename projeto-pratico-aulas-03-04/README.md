# 📱 Projeto Prático — Aulas 03 e 04
## Programação para Dispositivos Móveis · TADS 2026.1

Série de 14 exemplos progressivos cobrindo **JavaScript/TypeScript** (Aula 03) e
**Interface de Usuário I** (Aula 04). Cada passo é um `App.js` independente,
pronto para rodar em **snack.expo.dev**.

---

## 🗺️ Mapa de Aprendizagem

```
AULA 03 — Estrutura e Linguagem
├── passo-01  Variáveis: var / let / const / tipos primitivos
├── passo-02  Funções tradicionais e Arrow Functions
├── passo-03  Arrays: .map() / .filter() / .reduce() / spread
├── passo-04  Objetos, Destructuring e Spread de objeto
├── passo-09  Template Literals e formatação de strings
└── passo-10  Async/Await + useEffect + simulação de API

AULA 04 — Interface de Usuário I
├── passo-06  Flexbox: eixos, justifyContent, alignItems, flex
├── passo-07  TextInput + formulário com validação
├── passo-08  Botões: Button / TouchableOpacity / Pressable
└── passo-11  Image (resizeMode) + ScrollView horizontal + .map()

INTEGRAÇÃO (Aulas 03 + 04)
├── passo-05  useState — estado e interação básica
├── passo-12  Mini-App: Calculadora de IMC  ⭐⭐
├── passo-13  Mini-App: Lista de Tarefas    ⭐⭐⭐
└── passo-14  Mini-App: Perfil de Aluno     ⭐⭐⭐ (app completo)
```

---

## 🚀 Como usar

1. Acesse [snack.expo.dev](https://snack.expo.dev)
2. Apague o conteúdo do `App.js` padrão
3. Cole o conteúdo do passo desejado
4. Escaneie o QR code com o **Expo Go** ou use o emulador web

## 💡 Dicas para o aluno

- **Não copie, digitie!** Digitar o código cria memória muscular.
- Cada passo tem comentários explicando *por que* o código funciona assim.
- Nos passos de integração, tente identificar quais conceitos das aulas 03 e 04 aparecem.
- Modifique os dados (nomes, notas, cores) para personalizar os exemplos.
